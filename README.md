# 變形金剛：台灣大富翁 (Transformers: Taiwan Monopoly)

一款融合經典「大富翁 (Monopoly)」遊戲機制、台灣知名景點地標，以及「變形金剛 (Transformers)」世界觀的跨界桌面博弈網頁遊戲。

---

## 🌟 遊戲特色亮點

1. **自訂玩家人數與控制權 (2 ~ 4 人)**：
   - 開局可自由選擇 2 人、3 人或 4 人參戰。
   - 每個席位皆可指派為 **真人玩家 (Human)** 或 **電腦 AI (Bot)**，支援單人與 AI 對戰，亦支援多位好友同機輪流遊玩 (Pass-and-Play)！
   - 提供三段初始能量金設定：$10,000 (速戰局)、$15,000 (標準局)、$20,000 (富裕局)。

2. **變形金剛主角群專屬技能**：
   - **柯博文 (Optimus Prime / 博派領袖)**：受【領導母體】庇佑，開局額外獲得 $500 能量儲備。
   - **大黃蜂 (Bumblebee / 偵查先鋒)**：啟動【超速偵查】，若擲出雙骰 (Doubles) 額外獲得 $200 巡航補貼。
   - **密卡登 (Megatron / 狂派霸主)**：憑藉【霸王威壓】，購買地產享 10% 成本折扣。
   - **天王星 (Starscream / 空戰指揮官)**：具備【超音速匿蹤】，踩中對手無建築地產有 20% 機率匿蹤免收過路費。
   - *(可選角色：鐵皮 Ironhide、聲波 Soundwave)*。

3. **台灣環島 40 格大地圖 (Taiwan Landmark Board)**：
   - **8 大色系地產**：台北 101、淡水漁人碼頭、高雄愛河灣、駁二特區、台南安平古堡、阿里山、逢甲夜市、台中國家歌劇院、新竹科學園區、太魯閣、知本溫泉、墾丁等。
   - **台灣高鐵 4 大樞紐**：高鐵台北站、高鐵台中站、高鐵台南站、高鐵左營站（持有越多站，過路費成倍暴增）。
   - **公共事業**：台灣電力能量電廠、台灣水資源水庫。
   - **特殊格子**：起點 (GO)、賽博坦維修基地 (監獄)、日月潭度假休整 (免費休息)、巡邏拘留所。

4. **命運 (Fate) 與 機會 (Chance) 專屬卡組**：
   - 結合台灣在地特色與賽博坦科幻故事：
     - *太空橋超速跳躍（直飛台北101）*
     - *台積電晶片大漲分紅（向所有人收錢）*
     - *高鐵超導推進*
     - *防空演習基地檢修*
     - *台南美食觀光節獎勵*
     - *博派特赦令（出獄卡）*

5. **地產壟斷與基地升級系統**：
   - 當同一位玩家集齊同色系所有地產時，達成「壟斷」，過路費翻倍！
   - 可在自己回合投入能量建造 **1 ~ 4 座「能量站 (Energon Pods)」** 及終極 **「賽博坦要塞 (Cybertron Fortress)」**，過路費飆升百倍！

6. **雙語體驗 (Bilingual: 繁體中文 & English)**：
   - **一鍵切換**：頂部選單提供 `🌐 Language` 切換按鈕，點擊即可在 **繁體中文 (Traditional Chinese)** 與 **English** 之間即時切換。
   - **國際版雙語棋盤 (Bilingual Board Tiles)**：全島 40 格地圖採用國際標準大富翁雙語並陳設計，主要語言粗體突顯、次要語言精緻副標呈現。
   - **完整在地化**：所有 UI 界面、角色天賦、40 張地契租金表、16 張機會/命運卡牌、彈窗互動、戰局即時日誌及內建說明手冊皆提供完整且道地的中英雙語翻譯。
   - **偏好記憶**：語言選擇會自動記錄於瀏覽器 `localStorage`，重新開局或重整頁面不遺失。

7. **沉浸式音效與流暢操作保障 (Web Audio & Watchdog Recovery)**：
   - 內建程序化純聲音合成器，無需載入外部肥大音檔，保證離線秒開（骰子聲、液壓機械步、買地金幣、升級和弦、警報、勝利號角）。
   - **防卡頓守護機制 (Watchdog Timer)**：內建非同步狀態監控，若偵測到非正常延遲或未響應，系統自動重整並推進回合。
   - **手動「🛠️ 恢復」按鈕**：頂部選單新增一鍵重整按鈕，可隨時復原行動按鈕。
   - **多重操作支援**：支援直接點擊中央 3D 骰子區，或直接按下鍵盤 **空白鍵 (Space) / Enter 鍵** 進行擲骰或結束回合！

## 🎮 快速啟動遊戲

本遊戲為純前端原生開發（Zero-Dependency HTML5 / CSS3 / ES6+）：

### 方法 1：直接雙擊打開 (推薦)
1. 進入本資料夾 `Richman`。
2. 直接使用任意瀏覽器（Google Chrome、Edge、Firefox、Safari）雙擊打開 `index.html` 即可立即暢玩！

### 方法 2：使用本機伺服器
如果你有安裝 Node.js，亦可在終端機執行：
```bash
npx serve .
```
或使用 Python：
```bash
python -m http.server 8000
```
然後在瀏覽器中開啟 `http://localhost:8000` 即可。

## 📜 遊戲核心規則摘要

| 機制 | 規則說明 |
| :--- | :--- |
| **回合流程** | 輪到行動的玩家點擊「擲骰子」，棋子依點數前進並觸發停留格事件；結束後點擊「結束回合」。 |
| **雙骰獎勵** | 若兩顆骰子點數相同 (Double)，可獲得再次擲骰機會！但若連續擲出 3 次雙骰，會因超速被立即送入維修監獄。 |
| **起點獎勵** | 棋子每經過或剛好停在起點 (GO)，皆可領取 $2,000 能量補助金。 |
| **過路費** | 停留在對手地產時必須支付過路費；無力支付且資金小於 $0 時宣告破產出局。 |
| **獲勝條件** | 當其他對手全數破產出局，最後屹立不搖的變形金剛將加冕成為「台灣與賽博坦總督」！ |
